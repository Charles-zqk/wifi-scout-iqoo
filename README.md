# WiFi 侦察兵 · 原生 Android 安装包工程（支持显示真实 Wi-Fi 名称 + 桌面小组件）

适配 **iQOO（OriginOS / Android 8.0–15）** 的原生 Kotlin 应用，编译后可生成标准 `.apk` 安装包。

## 原生版专属能力

1. **直接显示当前真实 Wi-Fi 名称（SSID）**：同时显示信号强度（dBm）、频段（2.4GHz / 5GHz / 6GHz）和协商速率（Mbps）；切换至蜂窝流量时自动显示运营商与流量模式。
2. **原生 4×2 桌面小组件**：在 iQOO 桌面双指捏合 → 原子组件 / 安卓小组件 → 添加 **「WiFi侦察兵」**，无需打开 App，在桌面直接看当前 Wi-Fi 名称、点 **`⚡测速`**，4 秒直接出下载/上传/延迟和电脑推荐评分！
3. **无浏览器 CORS 限制**：使用原生 `HttpURLConnection` 协程并发测速，海外 Cloudflare 节点与国内兼容 CDN 均可稳定直连。
4. **同名 Wi-Fi 自动归档对比榜**：依次连几个 Wi-Fi 和手机 5G 流量测速，自动以真实 Wi-Fi 名称排序，一眼找出附近最适合电脑直连的网络。

## 如何获取 `.apk` 安装包

### 方式一：GitHub 云端免费自动打包（最省心，电脑无需装任何软件）
1. 在 GitHub 新建一个仓库，把本文件夹 `wifi-scout-android` 里的所有文件上传进去。
2. 打开仓库顶部的 **Actions** 页面 → 等待约 2 分钟构建完成。
3. 在构建详情页底部的 **Artifacts** 下载 **`WiFi侦察兵-APK`**，解压得到 **`WiFi侦察兵-v1.0.apk`**，发到 iQOO 手机点击安装即可。

### 方式二：在本机直接编译出 `.apk`
如果已安装 JDK 17 + Android SDK（或让我帮你自动配置便携版命令行工具），在本目录执行：
```powershell
gradle assembleDebug
```
成品路径：`app/build/outputs/apk/debug/app-debug.apk`

## iQOO 手机安装后的两个小提示
- **显示真实 Wi-Fi 名称**：首次打开 App 时点击 **「一键授权显示 Wi-Fi 名称」**，并确保下拉控制中心的 **定位服务（GPS）** 处于开启状态（Android 系统隐私规则要求如此，本应用不收集也不上传任何位置数据）。
- **添加到 OriginOS 桌面**：在桌面空白处双指捏合 → **组件** → 下拉找到 **「WiFi侦察兵 · 桌面测速小组件」** 拖到桌面即可。
